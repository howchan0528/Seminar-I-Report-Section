# 報告二
 
- 日期：2026/10/20
- 講者：蔣惟丞 副教授 — 國立中正大學電機工程學系，智慧學習系統與決策智慧實驗室
- 題目：深度強化學習於多機器人系統學習與控制
## 簡介
 
單一機器人的能力有限，多部機器人協作可以擴大工作範圍（分散執行巡檢、監控、探索與搬運）、讓分工更細（同一任務中配置不同角色），並在障礙物或未知事件下透過協調提升適應力。常見的群體任務包括協同搬運、追捕與包圍、區域巡檢，以及足球比賽中的進攻、防守與支援分派。
 
本次演講的核心問題是：**如何讓多個自主學習的機器人，逐步形成穩定的集體決策？** 內容分為四個部分：
 
1. **自主學習**：從強化學習（RL）、Q-Learning 到深度 Q 網路（DQN）的基本原理。
2. **群體協作**：多機器人之間的互動關係、通訊限制，以及非平穩性與「合作停滯」問題。
3. **研究驗證**：講者提出的深度合作模型（DCM），在無通訊條件下讓機器人「估計合作」，並以掠食者－獵物、合作搬運模擬及實體機器人實驗驗證。
4. **階層式控制**：把複雜任務拆成子行為，再以行為融合網路整合，應用於 Webots 足球場與星海爭霸多代理對戰場景。
## 相關技術說明
 
### 一、強化學習基礎
 
**強化學習（Reinforcement Learning）**：代理人（Agent）與環境互動，以試錯法（trial-and-error）的方式學得策略。四個基本要素為：
 
| 要素 | 說明 |
| --- | --- |
| 代理人（Agent） | 與環境互動、做出決策的學習者 |
| 狀態（State） | 由環境資訊轉換而成 |
| 行動（Action） | 代理人可採取的動作，會造成狀態移轉 |
| 報酬（Reward） | 用來評估動作的好壞 |
 
**Q-Learning**：以表格記錄每個狀態下各行動（前、後、左、右）的價值 Q，透過報酬不斷更新。以迷宮找路為例，報酬設計為撞牆 −100、到達終點 +100、一般移動 0，代理人藉由反覆嘗試學到合適路徑。
 
**深度 Q 網路（DQN）**：當狀態是影像或高維感測資料時，表格無法容納所有狀態，因此改用神經網路做函數近似，輸入狀態特徵、輸出每個動作的價值估計 Q(sₜ, 上／下／左／右)，再據此選擇行動。
 
### 二、多機器人協作的挑戰
 
**三種群體互動關係**：
 
| 類型 | 說明 | 例子 |
| --- | --- | --- |
| 完全合作 | 所有機器人共享團隊目標 | 合作搬運、聯合追捕（Overcooked） |
| 完全競爭 | 不同個體的目標互相衝突 | 對抗遊戲與競賽（Bomberman） |
| 合作與競爭並存 | 共同完成部分任務，同時競爭資源或優先權 | Google Research Football |
 
**三種通訊架構**：
 
| 架構 | 做法 | 優點 | 限制 |
| --- | --- | --- | --- |
| 完全通訊 | 交換廣泛的狀態與動作 | 資訊最完整 | 聯合空間與傳輸成本較高 |
| 部分通訊 | 只分享指定的局部資訊 | 在協調性與成本間折衷 | 需設計共享內容與頻率 |
| 無通訊 | 只靠自身觀測與回饋學習 | 通訊負擔最低 | 較難推測夥伴意圖 |
 
講者的研究聚焦在最困難的無通訊架構：**在不交換訊息的情況下，如何建立合作行為？**
 
**非平穩性（Non-stationarity）**：當其他機器人也在更新策略時，每個機器人面對的環境會持續改變。機器人 A 改變策略 → 機器人 B 的經驗分布改變 → B 的學習目標跟著移動 → 群體決策產生震盪。也就是說，局部學習者的策略彼此耦合，個體改變行為，也同時改變了同伴的學習環境。
 
**合作停滯**：只考慮個體最優動作，可能讓整體任務無法前進，可分為兩類：
 
- **環境型停滯**：物件前進方向被牆壁或障礙物擋住，部分機器人持續前進，整體卻無法移動。
- **非環境型停滯**：沒有障礙物，卻因各機器人選擇不同方向，造成拉扯、物件掉落或僵持。
因此協同決策必須同時回答三個問題：我的下一步最好嗎（個體行動價值 Q 值）？這一步有助於合作嗎（群體合作傾向 C 值）？我知道同伴在做什麼嗎（可得資訊與通訊成本）？講者的核心想法是讓機器人「估計合作」，而不只是追求自己的 Q 值。
 
### 三、無通訊下的深度合作學習（DQN＋DCM＋ADF）
 
每個代理人都由三個部分組成：DQN 負責決策、深度合作模型（DCM）負責模仿其他代理人的意圖，再由行動決策函數（ADF）融合兩者的輸出。
 
**1. 深度 Q 網路（Double DQN 形式）**：使用兩個網路，主網路負責選擇行動，目標網路負責評估該行動的價值，以避免高估動作價值。經驗存入經驗回放緩衝區（Experience Buffer），以均勻抽樣訓練主網路，並定期更新目標網路。
 
**2. 深度合作模型（DCM）**：為每個代理人建構一個合作策略函數，估計在某個狀態下執行某個動作的合作傾向，數值介於 0 到 1 之間。輸入是局部感測的狀態與候選動作，輸出是每個候選動作的合作適切性評分。C 值依據任務結果調整：
 
| 情況 | 調整方式 |
| --- | --- |
| 發生合作停滯或失敗 | 依比例降低該狀態－行動對的合作評分 |
| 沒有停滯或合作失敗 | 讓該狀態－行動對的合作評分朝 1 提高 |
 
這樣 C 值始終維持在 0 到 1 之間。
 
**3. 行動決策函數（ADF）**：決策時，代理人把每個候選行動的 Q 值與 C 值依權重 w 加權相加，選擇融合後價值最高的行動。權重 w 決定機器人要多重視「合作」相對於「個體利益」。
 
### 四、模擬與實體實驗
 
| 實驗 | 環境設定 | 報酬函數 |
| --- | --- | --- |
| 掠食者－獵物 | 20×20 方格，兩個獵人捕捉一個獵物，行動為上下左右。獵物軌跡分為固定（矩形）與隨機（上下左右各 15%、原地不動 40%） | 兩獵人包圍獵物（距離 ≤ 1）+50；碰撞或出界 −10；其他 −0.1 |
| 合作搬運 | 7×7 方格，兩個代理人合作把物件搬到目的地，並需避障 | 物件送達目標區域 +50；碰撞或出界 −10；其他 −0.1 |
| 實體機器人 | 在場地中以群組機器人合作搬運物件、繞過障礙物 | — |
 
每一步 −0.1 的小懲罰會鼓勵代理人盡快完成任務；講者以影片展示隨機軌跡下的包圍過程，以及合作搬運的模擬與實體結果。
 
### 五、階層式合作與行為融合
 
**平面式與階層式學習**：平面式學習用單一策略同時學會所有技能，會面對高維度狀態、複雜回饋與學習干擾；階層式學習則把任務分成可重複使用的子行為，再依情境選擇、融合或指派。
 
**任務分解**：每個子模組對應明確、容易設計回饋的功能：
 
| 子行為 | 目的 | 獎勵設計 |
| --- | --- | --- |
| 導航與定位 | 接近指定目標 | 依自身任務的成功／失敗訊號 |
| 避障與安全 | 保持可行路徑 | 聚焦路徑安全 |
| 進攻行為 | 取得任務分數 | 達成得分條件時給正向訊號 |
| 防守行為 | 阻止失分 | 阻止失分時給正向訊號 |
| 合作搬運 | 保持一致方向 | — |
 
做法是先針對單一目標訓練各技能，再由融合網路整合。
 
**行為融合網路**：多個子行為 DQN（例如導航、射門、找球）各自提出候選動作，融合網路根據狀態動態調整各模組的影響力：
 
- **NETFW**：輸入影像或狀態特徵，產生各子行為的權重 wᵢ，最終行動為加權組合 a_final = Σᵢ wᵢ · aᵢ。
- **NETRF**：預測回饋並提供學習訊號，協助融合網路訓練。
**應用場景**：
 
- **Webots 足球場**：在模擬足球場中訓練機器人找球、帶球與射門。
- **星海爭霸（StarCraft II）多代理對戰**：5m_vs_6m（我方 5 名陸戰隊對敵方 6 名）與 8m_vs_9m（我方 8 名對敵方 9 名）。兩個場景都是我方人數較少，必須靠集火、走位等協同策略才能取勝。
**結論**：
 
- 平面式學習每個時間步直接選擇動作，面對複雜任務時可能需要較長的探索過程。
- 階層式強化學習以高層與低層策略分工，把複雜任務分解為多個子目標或技能。
- 技能可重複使用，有助於減少重複學習、提升學習效率。
- 階層式強化學習特別適合長期決策、機器人導航與多階段任務，但實際效能仍取決於技能設計與訓練方式。
## 心得報告
 
這場演講讓我最有感的是「非平穩性」這個概念。單一代理人時，環境是固定的；但多機器人時，每個機器人的策略都在變，彼此就是對方環境的一部分，學習目標會一直移動。這解釋了為什麼把單機的 DQN 直接複製到每台機器人上，常常學不起來，也讓我理解多代理強化學習真正的難點在「協調」而不是「個體能力」。
 
講者的 DCM 想法很直覺：既然不能通訊，就讓每台機器人自己學一個「這個動作合不合群」的分數 C，再和自己的 Q 值加權融合。C 值失敗就按比例下降、成功就朝 1 逼近，設計簡單卻能處理牆壁阻擋和互相拉扯兩種停滯。我好奇的是權重 w 如何設定，以及代理人數量增加時效果是否仍然穩定。
 
後半段的階層式控制則提醒我「任務分解」的價值：把足球拆成導航、找球、射門等子行為，每個子行為的獎勵都容易設計，再用 NETFW 學習融合權重。這和寫程式時的模組化很像，複雜問題先拆小，再組合起來。
